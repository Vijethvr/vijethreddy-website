Change the words on your website without editing code. Your edits stay in this browser until you download the updated file.

Publish your changes in 3 steps
  1. Click Download my changes to save content.json to your computer.
  2. Open GitHub → Upload files. Drag the downloaded content.json file onto the page.
  3. Click Commit changes. GitHub Pages will update your live website.

Uploading the file replaces the existing website text file. If GitHub refuses to replace it via Upload files, open content.json on GitHub and use its edit control instead. This editor does not need or request your GitHub password or access token.
